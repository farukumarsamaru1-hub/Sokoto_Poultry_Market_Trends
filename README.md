# Poultry Market Trends in Sokoto State

A preliminary data science project examining poultry prices and market activity in Sokoto State, Nigeria.

## Project Overview

This project organizes preliminary information about farmer and dealer prices for eggs and broiler chickens. It also discusses selected costs and identifies data that would be needed for more complete analysis.

## Study Scope

- Study window: 1–30 October 2026
- Preliminary respondent register: 5 profiles (3 farmers and 2 dealers)
- Focus: reported prices, selected cost components, and data quality

## Important Limitations

The sample and number of dated observations are limited. Some reported market price ranges still need their sources and observation methods confirmed. The available data is not sufficient for a reliable time-series forecast, so the report does not present one or fill gaps with invented data.
